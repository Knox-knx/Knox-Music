# Privacy

- No account, no email, no KNOX cloud, no analytics.
- Listening history, favorites, playlists, files: stored only in the local database on your device.
- Backups are files *you* create and keep.
- Network traffic exists only when you use online providers:
  - **Search:** the query text goes to each enabled provider (required to get results).
  - **Streaming:** audio is fetched from that provider's CDN.
  - **Nothing else** (no history, filenames, or playlists) is uploaded.
- Disable all online providers to run 100% offline on your local library.
